What is Unblocked Games G+?

Unblocked Games G+ is a free browser game collection built for the moments when you have five minutes and a Chromebook. The site combines two things: a large catalogue of third-party HTML5 games loaded in an isolated iframe, and a set of original local fallback games that are served from this domain. The wrapper is static and fast, and the local games keep working even when an external host is filtered.

The catalogue focuses on the games people actually search for: 2048, Snake, Tetris, Flappy Bird, Pac-Man, Chess, Minesweeper, Neon Slope and a full Cookie Clicker. Each game has its own page with controls, strategy tips and a saved high score.

No installs, no plugins

Every game is plain HTML5 canvas and JavaScript. There is no Flash, no emulator, no ROM download and no browser extension to install.

Built for school Wi-Fi

The site is a static GitHub Pages deployment. There are no game servers to time out and no third-party embeds that school filters can block.

Local high scores

Scores and saved games live in your browser's localStorage. You get persistence without an account or a cloud sync prompt.

Touch and keyboard

Arrow keys, WASD, mouse, swipe and on-screen D-pads are supported. The layout adapts to phones, tablets and Chromebooks.

No pop-ups or redirects

Clicking a game opens a page on this site. There are no fake download buttons, no new-tab redirects and no interstitial countdowns.

Original game code

The local fallback games are original implementations. The external catalogue is hosted by third parties and credited on each game page. The chess rules engine uses the open-source chess.js library under its BSD-2-Clause licence.

How to play unblocked games on a school Chromebook

School networks usually block game portals at the domain level, not the browser level. That is why a lightweight static site has a better chance of loading than a portal that pulls games from a dozen external hosts. Here is the short version of getting a game running without fighting the network:

  • Open the game page directly. Every title has a stable URL under /games/, so you can bookmark it instead of searching again.
  • Let the page finish loading once. Assets are small and same-origin, so the first load is the slowest. After that the browser cache does the work.
  • Use fullscreen. The fullscreen button (or the F key) hides browser chrome and gives the canvas more room, which also reduces accidental scrolling.
  • Keep sound off in class. Press M or use the sound button. The game remembers your preference on that device.
  • Your score is local. Clearing browser data will clear saved scores. Nothing is tied to a school account.

If a game does not respond to the keyboard, click the game area once. Browsers only send key events to the focused element, and clicking the stage makes it the active target.

Unblocked Games G+ FAQ

What is Unblocked Games G+ (GamePlus Edition)?

Unblocked Games G+ is the name students search for; GamePlus Edition is the same site under the shorter GamePlus brand. Both names lead to this catalogue of 786+ browser games, local fallback games and game guides.

Why do some games load from another website?

The larger third-party catalogue is embedded in a sandboxed frame. We do not add the original site’s ad or tracking scripts; the game itself loads from its own host when you press Play. If that host is blocked, use the local fallback game linked on the page.

Are these games really unblocked?

Unblocked Games G+ is a static website with no downloads, no installs and no accounts. It is designed to load over ordinary HTTPS, which is why it works on most school Chromebooks and office networks when other game portals are filtered.

Do I need to download or install anything?

No. Every game runs directly in the browser with HTML5 canvas, JavaScript and CSS. There are no plugins, extensions, emulators or ROM files to install.

Will the games work on a school Chromebook?

Yes. The site is built for low-power Chromebooks: no external fonts, no large image files and no WebGL requirement. Each game loads only the code it needs.

Is my progress saved?

High scores, boards and clicker progress are saved in your browser using localStorage. Nothing is uploaded to a server and no account is required.

Are the games safe to play at school?

The local fallback games are original self-contained HTML5 code. The larger catalogue embeds third-party games in an isolated iframe, but this site does not add the original wrapper’s ad or tracking scripts. The only scripts we add are page analytics.

How often are new games added?

New games are added as they are built and tested. The full catalogue is always available on the All Games page, and the sitemap is updated with every release.

Can I play on a phone or tablet?

Yes. Every game has a responsive layout and touch controls. Games that need direction input show an on-screen D-pad or swipe gestures.

How are the play counts calculated?

The number next to each game is a community popularity estimate based on page activity across the site. It is a quick signal of what people are playing, not a live concurrent-player counter.

Can I play two-player games on one device?

Yes. Pong, Tic-Tac-Toe, Connect Four and Air Hockey all have local two-player modes for one keyboard or touchscreen. No second account or lobby is needed.

Is Unblocked Games G+ free?

Yes, completely free. There is no paywall, no subscription and no login. The project is open source and the game code is original.
