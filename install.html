Install Unblocked Games G+

Add the G+ catalogue to your home screen or desktop and open it like a normal app — no store, no account and no admin install.

Android iPhone / iPad Windows / Mac Chromebook

One tap from the home screen

The site is a Progressive Web App (PWA). After installing, it opens in its own window, remembers the catalogue locally, and loads the app shell even on a weak connection. The local fallback games are cached for offline play.

Browse games first

If the button says “Continue in browser”, your browser does not expose an install prompt. Use the platform steps below.

Android — Chrome, Edge or Samsung Internet

  1. Open unblockgameplus.github.io in Chrome, Edge or Samsung Internet.
  2. Tap the three-dot menu in the top-right corner.
  3. Choose Install app or Add to Home screen.
  4. Confirm with Install. The G+ icon appears on your home screen.

On some Chromebooks and Android tablets the install icon appears directly in the address bar. Tap it instead of opening the menu.

iPhone and iPad — Safari

  1. Open the site in Safari (not Chrome or Firefox).
  2. Tap the Share button — the square with an arrow pointing up.
  3. Scroll down and choose Add to Home Screen.
  4. Name it “Games G+” and tap Add.

iOS does not show an automatic install prompt; the Share menu is the official route.

Windows and Mac — Chrome or Edge

  1. Open the site in Chrome or Edge.
  2. Look for the small install icon at the right side of the address bar, or open the browser menu.
  3. Choose Install Unblocked Games G+.
  4. Confirm Install. The app gets its own desktop shortcut and window.

On macOS, the app appears in Launchpad and Applications. On Windows, it appears in the Start menu.

Chromebook — ChromeOS

  1. Open the site in Chrome on the Chromebook.
  2. Use the install icon in the address bar, or the three-dot menu → Install.
  3. Confirm the install. The app appears in the launcher and can be pinned to the shelf.

If your school disables PWA installation, bookmark the site instead; the games still work in a normal tab.

Firefox, Safari on Mac and older browsers

These browsers do not support full PWA installation. You can still use the site normally and add it to your bookmarks or favourites. For the standalone app experience, use Chrome or Edge on desktop, or Safari on iPhone/iPad.

What works offline?

The app shell, the catalogue page and the local fallback games are cached after they are opened once. Third-party games load from their own hosts, so they still need an internet connection. If a third-party host is blocked, use the local fallback button on the game page.

Install FAQ

What does installing Unblocked Games G+ do?

It adds a shortcut to your home screen or desktop and opens the site in a standalone window without the browser address bar. It does not download the whole catalogue; the app shell and local fallback games are cached by the service worker.

Do I need to install anything on a school Chromebook?

No admin install is required. Chrome on a Chromebook can add the site to the shelf or install it as a PWA from the browser menu. If the install option is disabled by your school, use the normal browser tab and bookmark the page.

Do the installed games work offline?

The local fallback games work offline after they have been opened once, because their assets are cached. Third-party games load from their own hosts and still need an internet connection.

Why is there no install button on my browser?

Firefox and some older browsers do not support PWA installation. Use Chrome, Edge or Samsung Internet on Android, Safari on iPhone/iPad, or Chrome/Edge on Windows, Mac and Chromebook.

Can I uninstall it later?

Yes. On Android, long-press the icon and choose Uninstall or Remove. On desktop, open the app menu and choose Uninstall. On iPhone/iPad, long-press the home-screen icon and choose Remove Bookmark.
