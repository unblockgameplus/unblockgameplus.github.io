About Unblocked Games G+ (GamePlus Edition)

A fast browser game catalogue with local fallback games, built for school Chromebooks and short breaks.

Why this site exists

Most "unblocked games" sites are directories that embed games from other domains. That works until one of those domains is filtered, the embed goes down, or a redirect chain turns a two-minute break into a browser history lesson. Unblocked Games G+ takes a hybrid approach: a large third-party catalogue is loaded only when you press Play, and a set of original local fallback games is served from this domain so there is always something that works.

How the games are made

The local fallback games are original HTML5 implementations. They use the 2D canvas API, DOM elements, CSS and vanilla JavaScript, with no game engine and no external runtime. The chess move generator and legality rules use the open-source chess.js library under its BSD-2-Clause licence. The external catalogue is owned by its respective hosts and is credited on each game page.

What is stored on your device

High scores, saved boards, cookie-clicker progress and the sound preference are stored in your browser's localStorage. No account is created, and none of that data is sent to a server. The site uses Google Analytics and Microsoft Clarity for aggregate page analytics; those scripts are loaded from their own domains and are described in the privacy page.

Adding or requesting games

The project is open source at github.com/unblockgameplus/unblockgameplus.github.io. Bug reports, game requests and pull requests are welcome there. If you are a developer, each game lives in assets/js/games/ and the page content is generated from src/data/games.mjs.

Contact

Use the contact page or open an issue on GitHub. For a specific game, include the game name and the device/browser you were using so the report can be reproduced.
